How this works

One document describes the edit. The preview paints it and the export writes it, from the same numbers — so what you approve is what comes out.

Scrubbing is frame-exact. A <video> element can only land on about every eighth frame; this decodes a whole group of pictures at once and keeps it, so stepping backwards costs nothing. Watch the counters.
